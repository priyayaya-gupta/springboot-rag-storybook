# Rag-storyBook

A Retrieval-Augmented Generation (RAG) application built with Spring Boot and Qdrant.

## Features
- Upload PDF documents
- Generate vector embeddings
- Store embeddings in Qdrant
- Semantic search
- Context-aware question answering

## Tech Stack
- Java
- Spring Boot
- Qdrant
- Ollama/OpenAI/Gemini (jo bhi use kiya hai)
